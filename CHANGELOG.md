# Changelog

All notable changes to the Bot-B-Gone framework are recorded here. The current
version is stored in the [`VERSION`](VERSION) file. Format based on
[Keep a Changelog](https://keepachangelog.com/).

## [10.0.0] — 2026-06-23

### Changed
- **Community membership is now a feature, not a verdict.** Earlier versions
  treated community membership (paid subscribers, event attendees, verified
  purchasers) as a blanket override that forced every event from a member to
  "human." In practice that static allow-list auto-passed a large volume of
  automated traffic generated by members' own corporate security scanners —
  engagement that looked real but wasn't, inflating reported opens and clicks.
  Membership is now a high-trust signal that stays computed and available for
  optional weighting, but every event is screened behaviorally. A member whose
  only activity in a send is a sub-second scanner pre-click is now filtered.
  (`v2/classify.py`, `v2/ARCHITECTURE.md`, `v2/CLAUDE.md`, `v2/BENCHMARKS.md`,
  `v2/diagnose.py`)
- **README now documents all three implementations:** the recommended ML
  cascade (`/v2/`), the original dependency-free SQL model (`/model/`), and the
  soft-label research pipeline (`/ml/`).

### Removed
- Deleted `ml/score_gap.py`, an internal-only diagnostic that could not run
  outside its original environment and had no public value.

### Fixed
- Stopped tracking Python build artifacts (`__pycache__/`, `*.pyc`) that had been
  committed by accident, and broadened `.gitignore` to cover them repo-wide.

### Earlier history

Bot-B-Gone reached V10 through methodology iterations (V1–V9) developed
internally before the framework was open-sourced. The published release history:

- **2026-04-03 — V2 ML cascade.** Added `/v2/`: the four-layer cascade (Apple
  MPP stripping, scanner detection, Random Forest classification, community
  signal) with a per-publisher training framework, synthetic sample data,
  architecture and benchmark docs, and an ESP column map.
- **2026-03-31 — ML research pipeline.** Added `/ml/`: a soft-label XGBoost
  pipeline and experiment harness for mapping the probability spectrum between
  definitive bots and definitive humans.
- **2026-03-27 — Initial public release.** Methodology documentation (honeypots,
  click timing, velocity signals, open classification), the deterministic SQL
  model (`/model/bot_b_gone_filter.sql` — 13 click rules, 8 open rules,
  confidence and probability scoring), and the measurement kit (FP/FN guide,
  probability tuning, the Confidence Scorecard, and regenerable charts).
